# Security Policy

## Supported Versions

Only the latest deployment of CampusSpace on the `main` branch is actively supported with security updates.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Older releases   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CampusSpace:

1. **Do not create a public issue.**
2. Use GitHub's [Private Vulnerability Reporting](https://github.com/adhruv668-gif/campus-room-viewer/security/advisories/new) tool to submit your findings privately.
3. Alternatively, report directly to the security maintainers via email at `dhruv.anand2026@lpu.in`.

Please include:
- A description of the issue and potential impact
- Step-by-step reproduction instructions or proof-of-concept
- Proposed remediation steps (if known)

We acknowledge all reports within 48 hours and coordinate fixes prior to public disclosure.
